# Emote Player

#### Need help join the [discord](https://discord.gg/C4jfjBmvWQ)

An emote player for wobbly life.
it has all emotes but no text bubble like projectmods.
press `f4` to open it.

## Instalation 

Extract the zip and in the `Release` folder you will find the .dll drag that into the `plugins` folder:
 `C:\Program Files (x86)\Steam\steamapps\common\Wobbly Life\BepInEx\plugins`

The path maybe different if bepinex is loacated somewhere else.

emote player now has custom config
```ini
DisableGameInput = true
KeyToggle = f4
```
change these settings in `C:\Program Files (x86)\Steam\steamapps\common\Wobbly Life\BepInEx\config\EmotePlayer.cfg`
or download [BepInExConfigManager](https://github.com/sinai-dev/BepInExConfigManager/releases/tag/1.3.0)

## Dependencies

 - [BepInEx 5.4.23.5](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5)

 - [UniverseLib.Mono](https://github.com/sinai-dev/UniverseLib/releases/tag/1.5.1)
